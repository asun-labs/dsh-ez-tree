## 0.1.1 历史验证

## Windows x64

2026-11-25 在 Windows x64 本机完成以下验收。桌面实际发行 ZIP 的字节数、SHA-256 与逐文件清单以同版本 `releases/runtime.json` 为准。

- 86 个固定上游文件逐项来源哈希通过；全部 15 个预设通过参数验证及真实渲染。
- 实际打包程序在隔离工作目录和空 PATH 下执行，未借用开发 checkout 或系统 Node。
- 完整编辑器和离线场景正常，打包后截图已目视检查。
- 引擎导出真实 GLB、透明 PNG 与 JSON。GLB 验证二进制头、长度、网格和嵌入图片，JSON 验证 seed 往返一致。
- 官方 MCP SDK 建立真实 stdio 会话，列出预设、读取参数、生成和导出；路径越界与覆盖请求被拒绝。
- 同账号隐藏 GUI 与 MCP 同时运行，参数与导出正确，无 Chromium 缓存锁冲突。测试不显示窗口或占用用户焦点。
- 从精确发行 ZIP 安装到隔离账号目录后，复验完整 UI 和 MCP，执行关闭、重开、卸载；项目数据保留。
- 由受信 0.1.0 运行时升级至 0.1.1，验证原参数项目与旧 MCP 可执行路径保留；缺少或损坏的新版本不会替代已校验的旧版本。
- 从旧的 scoped 插件包迁移为唯一 `dsh-ez-tree` 条目，验证 bundle、Loader、启用/停用状态、无关插件配置、失败恢复与重复执行。
- 安装器回归覆盖 ZIP/文件摘要、危险路径、目录链接、取消、账号隔离、下载失败、原子替换失败、恢复失败保留备份及并发目录创建。
- Host/Client 回归覆盖 owner、账号及 epoch、默认停用的连接器/技能、连接器环境配置、账号切换清理和轮询互斥。
- 使用官方 DSH `0.2.2-rc.3` CLI 在隔离 `DSH_HOME` 安装发行 TGZ，核对 bundle、实际 Host、客户端 Loader、原生侧栏和真实 RPC 状态。无头浏览器无页面错误。

实际桌面验收报告保留在开发机 `.build/installed-verification.json` 和 ZIP 附带的本地验证 JSON；原生插件报告在 `.build/native-install/*/report.json`。公开发布提供去除本机路径的验证摘要。签名与安装不是同一验证项：首版 Windows 程序未进行代码签名。

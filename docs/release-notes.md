# EZ-Tree 0.1.0

完整 EZ-Tree 编辑器、Seal / DeepSeek Harness 插件、MCP 和内置技能的首个统一发行版。

- 完整编辑器：15 个预设、实时三维预览、枝叶与树皮参数、环境和镜头、参数 JSON 导入导出、带纹理 GLB 与透明 PNG。
- 独立桌面包带齐运行时和离线资源，无需另装 Node.js。Seal 插件提供受校验安装、打开、状态、关闭和卸载，保留用户项目。
- MCP 使用随包嵌入 Node 启动器与隐藏渲染器，提供预设、参数、生成和导出 4 个工具。GUI 与 MCP 可以同时运行，通过 JSON 交接项目。
- 内置 `ez-tree` 技能；连接器与技能安装到当前账号，默认停用，再按需选择会话能力。
- 保留上游来源、作者、许可及逐文件 SHA-256。

下载插件 TGZ，在 Seal 插件管理中导入并启用，进入「树木生成器」安装桌面应用。单独使用时解压桌面 ZIP 并运行 `EZ-Tree.exe`。所有附件摘要见 `SHA256SUMS`。

Windows x64 已完成真实打包程序、完整 UI、带纹理导出、官方 SDK stdio、并发、已安装实例生命周期，以及官方 DSH CLI 插件安装和原生界面验收。验证全程隐藏窗口，不占用鼠标键盘或焦点。

macOS/Linux 尚无本次实测支持声明；Windows 首版未签名。npm 登录验证返回 401，本次通过 GitHub Release 分发，不宣称已发布 npm。

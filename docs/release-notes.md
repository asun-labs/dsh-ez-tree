# EZ-Tree 0.1.2

安装启用后，在当前会话使用内置 `ez-tree` 技能，即可在宿主现有的右侧浏览器中打开真正的三维树木编辑器。移除常驻“树木生成器”管理入口。

- 插件携带完整编辑器、纹理与解码器，新会话流程无需另装独立桌面程序或配置 MCP。
- 原生会话工具和手动参数操作共享同一项目。实际生成并核对参数摘要后才提交修订，冲突或失败保留已提交状态。
- GLB、透明 PNG 与裸参数 JSON 保存至当前会话工作目录；工具返回实际路径与文件摘要。
- 修复新版原生 DSH 已认证请求被重复准入导致的 HTTP 400。
- 内置技能直接由宿主发现；仅停用与旧版原始内容完全匹配的托管副本，不覆盖用户修改。
- 保持正式包名 `dsh-ez-tree`，保留旧名称升级迁移、独立桌面/MCP、项目与导出兼容。

新安装请下载 `dsh-ez-tree-0.1.2.tgz`。已有旧名称安装时，先关闭宿主，使用包内 `lib/upgrade-profile.mjs` 按 [升级说明](https://github.com/asun-labs/dsh-ez-tree/blob/v0.1.2/docs/upgrade.md) 迁移，避免旧新条目同时激活。所有附件摘要见 `SHA256SUMS`。

完整编辑器、真实 GLB/PNG/JSON 导出、MCP stdio、并发、数据保留及插件迁移均须通过发行门禁。验证全程隐藏窗口，不占用鼠标键盘或焦点。

本次桌面发行包为 Windows x64，未进行代码签名。npm 发布以有效凭据和实际结果为准，不把 GitHub Release 当作 npm 发布。

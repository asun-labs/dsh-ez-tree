# EZ-Tree

使用当前会话已连接的 EZ-Tree MCP。先列出工具与树种预设，读取参数；缺少连接时，引导用户在 EZ-Tree 插件中安装桌面应用、准备 MCP，并在当前会话选择该连接器。

以现有预设为起点，根据用户意图调整树干、枝条、树叶和 seed。相同完整参数及 seed 用于复现结果。保留一份参数 JSON，便于在完整编辑器中继续调整。

- 游戏植被：先确认目标复杂度，降低分枝数量、层数、截面段数与叶片数量，再检查实际顶点和三角形数量。
- 外观变体：保留结构参数，只改变 seed；逐个生成与导出，记录种子和输出文件的对应关系。
- 交付三维模型使用 GLB；预览使用 PNG；可编辑参数使用 JSON。GLB 是静态模型，不承诺包含编辑器的风吹着色器动画。

使用 MCP 实际返回的工具名称与 schema，不猜测参数名称。只有导出成功并返回真实文件路径才算完成；回复附文件路径、使用的预设/种子和实际复杂度。导出目录由应用启动配置限定，不能通过文件名穿越目录或覆盖已有成果。

需要肉眼调整树形、材质、镜头与环境时，通过插件打开完整编辑器。MCP 的生成实例与已打开的编辑器实例独立；通过导出的参数 JSON 在两者之间传递，不能声称实时控制了另一个窗口。

# EZ-Tree

首先调用 `ez_tree_open_editor`，在宿主现有的右侧浏览器中加载当前会话的三维编辑器。等待工具明确返回真实渲染成功；不要把导航请求或加载中说成已经完成。无需让用户去一级菜单安装应用、手工配置 MCP 或另行安装此技能。

读取 `ez_tree_editor_get` 的当前项目、预设和修订号。使用 `ez_tree_editor_generate` 修改需要变化的部分参数，必要时携带 `expectedRevision`；此工具和用户手动调参操作的是同一个项目。发生修订冲突时重新读取，不用旧的完整参数覆盖用户刚做的编辑。

- 游戏植被：先确认目标复杂度，降低分枝数量、层数、截面段数与叶片数量，再检查实际顶点和三角形数量。
- 外观变体：保留结构参数，只改变 seed；逐个生成与导出，记录种子和输出文件的对应关系。切换会话不代表可以读写另一会话的树。
- 交付三维模型使用 GLB；预览使用 PNG；可编辑参数使用 JSON。GLB 是静态模型，不承诺包含编辑器的风吹着色器动画。

使用 `ez_tree_editor_export` 导出 GLB、PNG 或裸参数 JSON。只有返回实际路径、修订号和摘要才算导出成功。结果保存到当前会话工作目录的 `models/ez-tree`，不接受任意输出目录、不覆盖已有文件。回复给出文件路径、预设/seed 和实际顶点或三角形数。

用户可直接在眼前面板调整枝叶、材质和镜头。继续处理前重新读取项目，不假设用户没有手动修改。面板关闭、WebGL 不可用或当前会话不在前台而尚未渲染时，如实说明工具错误或待打开状态，不能生成占位图片代替可编辑的三维场景。
